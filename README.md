# cheongju-vs-songdo-simulation
1989~2026 청주(반도체)와 송도(바이오)의 역사적 성장 지표를 비교하는 Streamlit 시뮬레이션 대시보드


# 프로젝트 개발 지시서: 기업 유치와 신도시 개발의 경제·지리적 효과 분석 웹 플랫폼

## 1. 프로젝트 목표

한국지리 수행평가 「파이썬 시뮬레이션을 활용한 기업 유치와 신도시 개발의 경제·지리적 효과 분석」을 기반으로, 청주 반도체 산업 발전 사례와 인천 송도국제도시 개발 사례를 비교 분석하는 전문적인 데이터 시각화 웹사이트를 제작한다.

이 프로젝트는 단순한 보고서 열람 페이지가 아니다. 사용자가 연도를 직접 변경하고, 두 지역의 경제 규모·인구·기업 자본·국가 예산을 비교하며, 지역 발전의 공간적 흐름과 개발 정책의 차이를 탐색할 수 있는 인터랙티브 분석 플랫폼이다.

프로젝트의 핵심 질문은 다음과 같다.

**“신도시를 직접 개발하는 방식과 기업을 유치하는 방식 중 어떤 전략이 지역 경제 성장, 인구 유입, 일자리 형성 및 공공 예산 활용 측면에서 더 효율적인가?”**

이 질문에 미리 정해진 결론을 강요하지 않는다. 수집된 자료와 분석 결과를 바탕으로 사용자가 직접 비교하고 판단할 수 있도록 한다.

## 2. 반드시 지켜야 하는 개발 원칙

- HTML, CSS, JavaScript를 중심으로 완성도 높은 웹사이트를 구현한다. 필요한 경우 기존 프로젝트의 프레임워크와 구조를 활용한다.
- 이미 존재하는 프로젝트라면 기존 파일 구조, 실행 방식, 라이브러리, 디자인 시스템을 먼저 파악한다.
- 기존 프로젝트가 있다면 관련 없는 파일이나 기능을 삭제하거나 임의로 재작성하지 않는다.
- 보고서에 포함된 탐구 동기, 분석 사례, 수치, 해석, 한계 및 정책 제안을 보존한다.
- 존재하지 않는 공공데이터, API 응답, 통계 수치, 분석 결과를 실제 데이터인 것처럼 만들어 표시하지 않는다.
- 실제 데이터, 보고서에 기재된 수치, 사용자가 입력한 값, 예시 데이터, 가상 시뮬레이션 결과를 명확하게 구분한다.
- 데이터가 없거나 불완전한 경우 오류를 숨기지 말고 해당 항목에 데이터 부족 또는 검증 필요 상태를 표시한다.
- 모든 버튼, 연도 선택기, 그래프, 지도, 필터, 탭은 실제 기능을 수행해야 한다.
- 시각적으로만 완성된 모형이 아니라 실제 데이터를 연결하고 분석할 수 있는 실행 가능한 웹 애플리케이션을 제작한다.
- 화면의 일부만 구현하고 나머지를 빈 공간, 작동하지 않는 버튼 또는 임의의 통계로 채우지 않는다.

## 3. 전체 디자인 방향

공공기관의 지역개발 분석 시스템과 전문적인 경제 데이터 분석 플랫폼을 결합한 디자인을 적용한다.

### 디자인 콘셉트

- 주조색: 짙은 남색, 차콜, 흰색
- 보조색: 청주 데이터는 청록색 또는 파란색, 송도 데이터는 주황색 또는 금색
- 배경: 밝은 회백색 또는 선택 가능한 어두운 분석 화면
- 그래프: 축, 단위, 범례, 데이터 출처가 명확한 전문적인 시각화
- 지도: 실제 지리적 위치와 공간적 관계를 보여주는 지도
- 카드: 불필요한 장식 없이 핵심 수치를 강조
- 애니메이션: 연도 변경과 데이터 변화에 대응하는 짧고 자연스러운 전환 효과
- 반응형 디자인: 데스크톱, 태블릿, 모바일 화면 모두 지원

과도한 유리 효과, 불필요한 그라데이션, 과장된 3차원 그래프, 장식용 애니메이션은 사용하지 않는다. 시각적 완성도보다 데이터의 정확성, 가독성, 조작 편의성을 우선한다.

## 4. 웹사이트의 전체 구조

다음 페이지 또는 독립적인 콘텐츠 영역을 구현한다.

1. 메인 대시보드
2. 연도별 경제·인구 비교
3. 기업 자본 및 국가 예산 분석
4. 지도 기반 공간 발전 분석
5. 인구 구성 및 산업 인력 분석
6. 시뮬레이션 실험실
7. 데이터 출처 및 분석 방법
8. 탐구 보고서 및 최종 결론

상단에는 프로젝트명과 주요 메뉴를 배치한다. 현재 보고 있는 페이지를 명확하게 표시하고, 다른 분석 영역으로 이동할 수 있도록 한다.

## 5. 메인 대시보드

웹사이트에 처음 접속했을 때 가장 먼저 나타나는 화면이다.

### 상단 영역

프로젝트 제목:

「기업 유치와 신도시 개발의 경제·지리적 효과 분석」

부제:

「산업 입지, 도시 성장, 인구 이동 및 공공 투자 효율성에 관한 데이터 기반 비교 연구」

제목 아래에는 탐구 질문과 분석 대상인 청주 반도체 산업 사례 및 송도국제도시 개발 사례를 소개한다.

### 핵심 지표 카드

다음 지표를 카드 형태로 배치한다.

- 지역 경제 규모 변화
- 상주인구
- 일일 유동인구
- 누적 기업 자본
- 누적 국가 예산
- 기업 자본 대비 국가 예산
- 선택 연도 기준 두 사례의 차이

각 카드에는 선택된 연도, 값, 단위, 데이터 상태를 표시한다.

두 지역의 수치를 단순히 합산하거나 서로 다른 기준의 값을 직접 비교하지 않는다. 특히 기업 자본과 국가 예산이 누적 투자액인지, 연간 지출액인지, 특정 시점의 잔액인지 데이터 정의를 먼저 확인한다.

### 핵심 시각화

첫 화면에는 다음 요소를 배치한다.

- 두 지역의 경제 규모 변화 선 그래프
- 상주인구 및 유동인구 비교 그래프
- 기업 자본과 국가 예산 비교 그래프
- 연도별 변화량 요약
- 주요 분석 결과와 주의 사항

사용자가 연도를 변경하면 관련 카드와 그래프가 함께 갱신되어야 한다.

## 6. 연도별 비교 분석 페이지

### 연도 선택 기능

연도 선택 슬라이더와 숫자 입력 또는 드롭다운을 제공한다.

사용자가 특정 연도를 선택하면 해당 시점의 청주와 송도 데이터를 표시한다. 이전 연도와 다음 연도로 이동하는 버튼도 제공한다.

가능한 경우 시간에 따른 그래프 재생 기능을 구현한다. 재생을 중단하거나 다시 시작할 수 있어야 하며, 현재 선택된 연도가 화면에 명확히 표시되어야 한다.

### 주요 비교 항목

- 경제 규모 및 변화량
- 상주인구
- 일일 유동인구
- 누적 기업 자본
- 누적 국가 예산
- 인구 구성 비율
- 주요 산업 및 고용 특성

각 지표에는 두 지역의 값, 절대 차이, 비교 가능한 경우의 증감률을 표시한다.

증감률은 기준 연도의 값이 0이거나 존재하지 않는 경우 계산하지 않는다. 시작 시점이 다른 사례를 비교할 때는 달력 연도 기준 비교와 사업 시작 후 경과 연수 기준 비교를 구분한다.

### 그래프 요구사항

각 그래프는 다음 기능을 지원한다.

- 마우스 오버 시 상세 수치 표시
- 범례 클릭을 통한 데이터 계열 표시 및 숨기기
- 확대 및 축소가 필요한 그래프에서의 탐색 기능
- 단위와 축 이름 표시
- 데이터가 없는 연도 구분
- 보고서 기재값과 검증된 실측값의 구분
- 모바일 화면에서의 가독성 유지

가능하면 절대 수치 비교와 변화 추세 비교를 별도로 제공한다. 서로 규모가 크게 다른 값을 하나의 축에 표시하여 작은 값의 변화를 알아보기 어렵게 만들지 않는다.

## 7. 기업 자본과 국가 예산 분석

기업이 투자한 자본과 국가가 투입한 예산의 관계를 분석하는 영역이다.

### 주요 기능

- 연도별 기업 자본 변화
- 연도별 국가 예산 변화
- 두 항목의 누적 규모 비교
- 기준 연도 대비 증가액
- 동일한 시점에서의 지역 간 차이
- 기업 자본과 국가 예산의 비율
- 예산 투입 대비 경제 규모 변화에 관한 참고 지표

기업 자본 대비 국가 예산을 계산할 때 분모가 0이거나 데이터 정의가 서로 다르면 계산 결과를 표시하지 않는다.

경제 규모 증가액을 국가 예산으로 나눈 값은 단순한 비율 지표로만 표시한다. 이를 국가 예산의 실제 투자 수익률이나 기업 유치의 인과적 효과라고 단정하지 않는다.

기업 자본, 기업 투자액, 누적 투자액, 기업 자산은 서로 다른 개념이므로 원본 자료의 정의를 확인한 뒤 구분한다.

### 분석 결과 설명

그래프 아래에 선택된 데이터가 보여주는 사실을 자동으로 요약한다.

예시 형식:

- 선택 연도에서 기업 자본이 어느 지역에서 더 크게 나타나는가?
- 국가 예산은 어느 지역에 더 많이 투입된 것으로 기록되어 있는가?
- 경제 규모와 인구 변화가 같은 방향으로 움직이는가?
- 해당 비교만으로 기업 유치가 더 효율적이라고 결론 내릴 수 있는가?

마지막 질문에는 자료의 한계를 반영한다. 상관관계와 인과관계를 구분하고, 산업 경기, 기존 인프라, 광역도시와의 연결성, 정부 정책 및 사업 범위 차이를 함께 고려한다.

## 8. 지도 기반 공간 발전 분석

지도는 단순한 배경 이미지가 아니라 지역 발전의 공간적 관계를 탐색하는 주요 도구로 구현한다.

### 지도 기능

- 청주 및 송도의 실제 지리적 위치 표시
- 지역별 주요 산업 거점 표시
- 연도별 인구 및 산업 관련 데이터 표시
- 사용자가 선택한 연도에 따라 지도 정보 갱신
- 데이터가 있는 경우 지역 간 이동 또는 연결 흐름 표시
- 범례와 데이터 설명 표시
- 지도 확대, 축소, 이동 기능

Folium 기반 지도 또는 Leaflet과 같은 지도 라이브러리를 활용할 수 있다. 기존 프로젝트에서 다른 지도 라이브러리를 사용하고 있다면 불필요하게 교체하지 않는다.

### 공간 흐름 시각화

보고서에서 언급한 유선도는 지역 간 공간적 연결 또는 이동 흐름을 나타내는 시각 요소로 구현한다.

다만 실제 이동량이나 연결 관계를 입증하는 데이터가 존재할 때만 실제 흐름선으로 표시한다. 출발지, 도착지, 이동량 및 좌표가 확인되지 않은 경우에는 임의의 선을 실제 인구 이동이나 교통 흐름인 것처럼 그리지 않는다.

실제 흐름 데이터가 없다면 보고서에서 언급한 흐름의 출현 시점을 설명하는 주석이나 개념적 표현으로 대체하고, 실측 이동 데이터가 아니라는 사실을 표시한다.

지도에서 특정 지역이나 거점을 클릭하면 관련 데이터와 설명을 확인할 수 있어야 한다.

## 9. 인구 구성 및 산업 인력 분석

보고서에 제시된 산업 인력 구성과 지역의 인구 구조를 비교한다.

### 청주 사례

보고서에는 다음과 같은 인구 구성 설명이 등장한다.

- 20~30대 연구원 또는 엔지니어: 45%
- 40대 전문 엔지니어: 30%
- 협력사 종사자 및 주거 가족: 25%

초기 시점에는 20대 엔지니어 55%, 30대 엔지니어 25%라는 수치도 기재되어 있다.

이 수치들은 원본 보고서의 기록으로 취급하며, 실제 공식 통계로 검증되기 전에는 실측 인구 구성 통계라고 표시하지 않는다. 연도별 분류 기준이 달라진 경우에는 동일한 범주로 임의 통합하지 않는다.

### 송도 사례

보고서에는 다음과 같은 구성 비율이 기재되어 있다.

- 30~40대 바이오 연구직: 40%
- 국제학교 및 교육 관련 이주층: 45%
- 외국인 유학생 등: 나머지 비율

이 역시 보고서에 기재된 분석값임을 표시하고, 각 집단의 정의와 실제 통계 출처를 확인할 수 있도록 한다.

### 시각화 방식

- 연도별 누적 막대그래프
- 인구 구성 비율을 보여주는 도넛 차트
- 산업별 인력 구성 비교
- 연도별 구성 비율 변화 그래프

비율의 합이 100%가 아닌 경우 자동으로 조용히 보정하지 않는다. 원본 데이터, 합계, 검증 상태를 표시하고 오류 여부를 확인할 수 있도록 한다.

## 10. 시뮬레이션 실험실

이 페이지는 웹사이트의 핵심 기능이다.

사용자가 조건을 바꾸어 기업 유치 중심 전략과 신도시 개발 중심 전략의 결과를 비교할 수 있도록 한다.

### 사용자 조작 항목

- 초기 지역 인구
- 초기 경제 규모
- 초기 기업 자본
- 초기 국가 예산
- 연간 기업 투자 가정
- 연간 공공 투자 가정
- 가정한 인구 증가율
- 가정한 경제 성장률
- 분석 기간
- 기업 유치 전략과 도시 개발 전략의 투자 비중

각 입력값에는 단위, 기본값, 설명, 허용 범위를 표시한다.

### 시뮬레이션 결과

- 연도별 경제 규모 변화
- 인구 변화
- 누적 민간 자본
- 누적 공공 예산
- 두 전략의 결과 비교
- 조건 변경 전후의 차이
- 결과에 가장 큰 영향을 미치는 가정

### 시뮬레이션의 필수 규칙

1. 보고서에 기록된 과거 수치와 가상의 미래 예측을 구분한다.
2. 사용자가 입력한 조건에 따라 결과가 실제로 다시 계산되어야 한다.
3. 초기값, 계산식, 단위 및 적용 기간을 설명한다.
4. 실제 자료에서 추정하지 않은 성장률을 실제 통계인 것처럼 사용하지 않는다.
5. 사용자가 성장률 등을 입력하지 않았다면 근거 없는 기본값을 숨겨 적용하지 않는다.
6. 가정이 필요한 항목은 기본 시나리오의 가정값을 명확히 공개하거나 사용자가 직접 입력하도록 한다.
7. 시뮬레이션 결과에는 '가상 시나리오' 또는 '모형 계산 결과'라는 표시를 제공한다.
8. 새로 고침하거나 조건을 변경해도 입력값과 계산 결과의 관계가 일관되게 유지되어야 한다.

가능하다면 낙관적·기준·보수적 시나리오를 제공한다. 각 시나리오의 성장률과 기타 가정값을 화면에 명시하고, 가정을 바꾸었을 때 결론이 얼마나 달라지는지 비교한다.

## 11. 데이터 처리 및 오류 검증

원본 보고서에서는 일부 연도의 누적 수치 기록 오류와 데이터 전처리 문제가 언급되어 있다. 따라서 데이터의 정확성과 검증 상태를 별도로 관리한다.

### 데이터 처리 단계

1. 원본 데이터 불러오기
2. 연도와 지역명 표준화
3. 수치의 자료형 변환
4. 단위 통일
5. 중복 데이터 검사
6. 결측값 확인
7. 누적값과 연간값 구분
8. 연도별 데이터 정렬
9. 이상치 및 합계 오류 탐지
10. 검증 결과와 출처 기록

누적 데이터가 잘못 기재되었다는 이유만으로 모든 누적값을 자동으로 연간 데이터로 분리하지 않는다. 원본의 측정 기준과 계산 방법을 확인할 수 있는 경우에만 변환한다.

### 데이터 상태 표시

각 데이터에는 다음과 같은 상태를 부여한다.

- 검증된 공식 자료
- 원본 보고서 기재값
- 사용자 입력값
- 가상 시뮬레이션값
- 출처 확인 필요
- 결측 또는 계산 불가

서로 다른 상태의 값을 그래프에서 비교하는 경우에도 범례와 설명으로 차이를 명확히 알 수 있어야 한다.

### 데이터 파일 업로드

CSV 업로드 기능을 제공할 수 있다.

- 파일 형식 및 필수 열 검사
- UTF-8 및 한글 CSV 처리
- 연도, 지역, 지표명, 값, 단위 등의 열 매핑
- 숫자가 아닌 값에 대한 오류 안내
- 중복 행 및 결측값 탐지
- 업로드 전 미리보기
- 사용자의 확인 이후 데이터 적용
- 잘못된 파일에 대한 구체적인 오류 메시지

잘못된 파일을 업로드했을 때 기존 데이터가 임의로 덮어써지지 않도록 한다. 업로드가 성공했다고 표시하기 전에 실제 파싱과 검증이 완료되어야 한다.

## 12. 데이터 출처 및 연구 방법 페이지

이 페이지에는 분석에 사용된 데이터의 출처와 처리 과정을 공개한다.

가능한 경우 다음 정보를 기록한다.

- 자료명
- 제공 기관
- 원본 링크
- 수집 연도
- 수집 시점
- 지역 범위
- 지표 정의
- 측정 단위
- 전처리 방법
- 결측값 처리 방법
- 검증 상태

공공데이터 API를 실제로 연결한 경우에는 API의 응답 상태와 갱신 시점을 확인할 수 있게 한다. API 키가 필요한 서비스는 키를 코드에 직접 노출하지 않는다.

실제 API를 연결하지 않은 상태에서는 '실시간 공공데이터 연동'이라고 표시하지 않는다. API 연결이 실패하면 마지막으로 검증된 데이터와 연결 실패 상태를 구분한다.

## 13. 탐구 보고서 및 결론 페이지

원본 보고서의 탐구 흐름을 읽기 쉬운 형태로 재구성한다.

### 탐구 동기

지역 개발과 공간 불평등에 관한 한국지리 학습을 바탕으로, 신도시 개발에 투자하는 방식과 기업의 본사 또는 공장을 유치하는 방식의 경제·지리적 효과를 비교하고자 했다는 내용을 담는다.

### 비교 대상 선정

청주 반도체 산업 사례와 송도국제도시 개발 사례를 선택한 이유를 설명한다. 사업 시작 시점과 비교 기간이 서로 다르다는 점을 명시한다.

### 분석 방법

경제 규모, 상주인구, 유동인구, 기업 자본, 국가 예산 등의 지표를 비교하고, 파이썬과 데이터 분석·지도 시각화 도구를 활용한 분석 방법을 소개한다.

실제로 구현한 기능과 계획 단계의 기능은 구분한다.

### 주요 관찰 결과

보고서에 기록된 값에 따르면 청주 사례에서는 2026년 기업 자본 약 43조 원, 국가 예산 약 1조 2,700억 원, 상주인구 약 87만 명이 제시되어 있다. 송도 사례에서는 기업 자본 약 15조 원, 국가 예산 약 7조 3,000억 원, 상주인구 약 22만 명이 기재되어 있다.

이 값들은 우선 보고서에 기재된 수치로 표시한다. 공식 자료를 통해 확인하기 전에는 독립적으로 검증된 통계라고 표현하지 않는다.

### 연구의 한계

다음 내용을 명시한다.

- 두 사례의 사업 시작 시점이 서로 다르다.
- 청주 반도체 산업 사례와 송도국제도시 개발은 사업의 성격과 공간적 범위가 다르다.
- 청주는 기존 도시와 산업 기반의 영향을 받으며, 송도는 인천이라는 광역도시권에 속한다.
- 반도체 산업의 경기 변동과 산업별 투자 특성이 결과에 영향을 줄 수 있다.
- 국가 예산과 기업 자본의 산정 기준이 동일하지 않을 수 있다.
- 인구와 경제 규모의 변화만으로 특정 개발 정책의 인과적 효과를 확정하기 어렵다.

### 정책 제안

보고서의 문제의식을 유지하면서 다음 제안을 제시한다.

- 지방 이전 기업에 대한 지원을 세제 혜택에만 한정하지 않고 산학협력과 인재 채용으로 연결한다.
- 과학기술 분야 대학과 기업 연구소 간 협력 체계를 구축한다.
- 산업 기반과 교통·주거·생활 인프라를 함께 고려한다.
- 인구 감소 지역에 동일한 개발 모델을 일괄 적용하지 않고 지역별 산업 및 인구 구조를 분석한다.
- 공공 투자와 민간 투자에 대한 장기적 영향을 데이터 기반으로 평가한다.

결론에서는 기업 유치가 항상 신도시 개발보다 우월하다고 단정하지 않는다. 이 연구의 데이터와 가정 아래에서 어떤 차이가 관찰되는지 설명하고, 지역 여건에 따라 결과가 달라질 수 있음을 함께 제시한다.

## 14. 기술 구현 요구사항

- 기존 환경을 먼저 확인하고 HTML, CSS, JavaScript 또는 프로젝트에 이미 적용된 기술을 활용한다.
- 그래프 라이브러리는 Chart.js, Apache ECharts 등에서 프로젝트에 적합한 하나를 선택한다.
- 지도 라이브러리는 Leaflet 또는 기존 지도 시스템을 활용한다.
- 불필요하게 여러 라이브러리를 중복 설치하지 않는다.
- 데이터 처리 로직과 화면 렌더링 로직을 가능한 한 분리한다.
- 반복되는 지표 카드와 그래프는 재사용 가능한 컴포넌트 또는 함수로 구성한다.
- 숫자 포맷과 단위 표기를 통일한다.
- 모든 상호작용은 실제 상태 변경과 연결한다.
- 브라우저 콘솔 오류, 잘못된 데이터 참조, 차트 갱신 오류를 점검한다.
- 모바일 화면에서 그래프와 표가 잘리거나 조작 요소가 겹치지 않게 한다.
- API 연결 실패, 빈 데이터, 잘못된 CSV, 계산 불가 상황을 처리한다.

## 15. 최종 검수 조건

작업이 끝나면 다음 사항을 직접 확인한다.

- 첫 화면에 프로젝트의 주제와 핵심 지표가 표시되는가?
- 연도 변경 시 모든 관련 시각화가 갱신되는가?
- 청주와 송도의 데이터가 올바르게 구분되는가?
- 단위와 데이터 기준이 명확한가?
- 그래프의 범례와 축이 정확한가?
- 데이터가 없는 항목에 임의의 수치가 표시되지 않는가?
- 실제 자료와 시뮬레이션 결과가 구분되는가?
- 지도에 허위 이동 흐름이나 잘못된 위치가 표시되지 않는가?
- CSV 업로드와 오류 처리가 정상적으로 작동하는가?
- 버튼, 메뉴, 필터, 탭이 모두 작동하는가?
- 작은 화면에서도 정상적으로 표시되는가?
- 탐구 보고서의 주요 내용과 연구 한계가 보존되었는가?

문제가 발견되면 해당 기능을 수정하고 다시 검증한다.

## 최종 개발 지시

위의 모든 요구사항을 반영하여 실제로 실행 가능한 완성형 웹사이트를 구현한다. 먼저 기존 프로젝트 구조와 사용 가능한 데이터를 확인하고, 이후 데이터 모델, 화면 구조, 시각화, 사용자 조작 기능, 오류 처리 순서로 개발한다.

외형만 완성하거나 일부 기능을 설명문으로 대체하지 않는다. 실제 구현이 어려운 기능은 작동하는 것처럼 꾸미지 말고 현재 구현 상태와 필요한 데이터 또는 연동 조건을 명시한다.

최종 결과물은 한국지리 탐구 보고서를 기반으로 하면서도 경제 분석, 지리 정보 시각화, 데이터 처리, 시나리오 비교를 수행할 수 있는 전문적인 연구용 웹 플랫폼이어야 한다.
